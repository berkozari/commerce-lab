# DEV-001 — Project Initialization

## Goal
Create a clean pnpm monorepo with a working React app, TypeScript Express API, code-quality checks and initial smoke coverage.

## Acceptance criteria
- [ ] `pnpm install` succeeds and `pnpm-lock.yaml` is committed
- [ ] `pnpm dev` starts both applications
- [ ] `http://localhost:5173` loads and shows API status `healthy`
- [ ] `curl http://localhost:3000/api/v1/health` returns HTTP 200
- [ ] `pnpm typecheck` succeeds
- [ ] `pnpm build` succeeds
- [ ] `pnpm lint` succeeds
- [ ] `pnpm test` succeeds
- [ ] `.env` and generated artifacts are ignored by Git
- [ ] Changes are reviewed in a feature PR before merge

## Scope boundaries
PostgreSQL, Redis, Prisma, Tailwind/shadcn, TanStack Query, React Router, auth, Docker and GitHub Actions are intentionally implemented in subsequent tasks. This keeps the initial foundation reviewable and testable.
